# Messenger — мессенджер для iPhone (IPA через Sideloadly)

Мессенджер с современным интерфейсом: **сообщения, фото, смайлики, счётчик онлайна**.
**Python-сервер** (Flask + Socket.IO) + **HTML/JS-клиент**, который упаковывается
в iOS-приложение через **Capacitor** и собирается в **IPA** на бесплатном облачном
Mac (GitHub Actions). Установка на iPhone — через **Sideloadly**.

## Возможности

- 💬 Сообщения в реальном времени
- 📎 Отправка фото (автоматически сжимаются — грузятся быстро)
- 😊 Панель смайликов (140+ эмодзи)
- 🎨 Аватары с цветным градиентом для каждого участника
- 🟢 Счётчик «N в сети»
- ✨ Анимированный фон и плавные анимации сообщений

## Шаг 1. Запуск сервера

**Двойной клик** по файлу `ЗАПУСТИТЬ-СЕРВЕР.bat` — всё.

Или вручную в PowerShell:

```powershell
cd messenger
.\venv\Scripts\python.exe server\server.py
```

Сервер работает на `http://localhost:5000`. Для проверки открой этот адрес
в браузере — адрес сервера на экране входа подставится автоматически.

## Шаг 2. Подключение с айфона

**А) Оба устройства в одной Wi-Fi сети**

Адрес сервера: `http://IP-ТВОЕГО-ПК:5000`. Узнать IP: команда `ipconfig`
→ строка «IPv4-адрес» (например, `192.168.1.40`).

> Если айфон не подключается — Windows-брандмауэр блокирует порт. Разреши Python
> в брандмауэре (окно появляется при первом запуске) или выполни в PowerShell
> **от имени администратора**:
> `New-NetFirewallRule -DisplayName "Messenger" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow`

**Б) Через интернет (айфон в любом месте) — ngrok**

1. Скачай ngrok: https://ngrok.com/download, зарегистрируйся (бесплатно).
2. `ngrok config add-authtoken ТВОЙ_ТОКЕН` (один раз)
3. `ngrok http 5000` → скопируй адрес вида `https://xxxx.ngrok-free.app` —
   это адрес сервера для приложения.

## Шаг 3. Сборка IPA (без Mac, без установки программ)

1. Зарегистрируйся на https://github.com
2. Нажми **+** → **New repository** → имя `messenger`, тип **Public** → Create
3. На странице репозитория нажми ссылку **«uploading an existing file»**
4. Перетащи в окно браузера **всё содержимое** папки `messenger`
   (папки `server`, `web`, `.github`, файлы `package.json`, `capacitor.config.json` и т.д.)
5. Нажми **Commit changes**
6. **Проверь:** в репозитории должна быть папка `.github/workflows` с файлом
   `build-ipa.yml`. Если её нет (браузер мог пропустить скрытую папку):
   **Add file → Create new file** → имя файла введи `.github/workflows/build-ipa.yml`
   → вставь содержимое из локального файла `.github/workflows/build-ipa.yml` → Commit
7. Открой вкладку **Actions** (если спросит — разреши запуск workflows) →
   сборка **Build IPA** запустится автоматически, жди 5–10 минут
8. Когда появится зелёная галочка — открой сборку, внизу в **Artifacts**
   скачай **Messenger-IPA** (в архиве — `Messenger.ipa`)

> Совет: перед загрузкой можешь поменять `appId` в `capacitor.config.json`
> на свой, например `com.danil.messenger` (латиница, без пробелов).

## Шаг 4. Установка на iPhone через Sideloadly

1. Скачай Sideloadly: https://sideloadly.io (если попросит — поставь iTunes/iCloud
   с сайта Apple, не из Microsoft Store)
2. Подключи iPhone кабелем, разблокируй, нажми «Доверять»
3. Перетащи `Messenger.ipa` в окно Sideloadly
4. Введи Apple ID (лучше отдельный, т.к. логин вводится в стороннюю программу)
   → **Start**
5. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   свой Apple ID → **Доверять**
6. Открывай Messenger, вводи адрес сервера (шаг 2) и ник — общайся!

## Важные ограничения

- **Бесплатный Apple ID: приложение живёт 7 дней**, потом переустанови через
  Sideloadly (перетащи IPA → Start). С платным аккаунтом разработчика ($99/год) — 1 год.
- Чат работает, **только когда запущен сервер** на твоём ПК.
- История (включая фото) хранится в памяти сервера — последние 100 сообщений,
  очищается при перезапуске.
- Это учебный проект: нет шифрования и регистрации. Не отправляй личные данные.
